# Beheer van het onderzoek met GitHub
## Gebruik van GitHub

GitHub is gebruikt als platform voor het organiseren, opslaan en delen van de onderzoeksbestanden. Door gebruik te maken van versiebeheer blijft inzichtelijk welke bestanden zijn toegevoegd of aangepast gedurende het project.

## Structuur van de repository

De repository is onderverdeeld in verschillende mappen, waaronder:

tabellen
scripts
competenties
Figuren
Bronnen

In deze mappen staan alle afbeeldingen, tabellen en scripts opgeslagen, deze zijn in de readme zichtbaar gemaakt via hyperlinks waardoor de gebruiker rechtstreeks naar de afbeelding word doorgestuurd. In de map tabellen staan alle tabellen uit het onderzoek opgeslagen. In de map scripts staat het volledige script met daarbij stap voor stap een uitleg wat er precies wordt gedaan en wat het doel is van de commandos. Ook staan hier aparte stukjes script die zijn gebruikt voor specifieke doelen in de materiaal en methode, zodat het makkelijker te vinden is wat er is gedaan. In de map competenties staan alle beherings vaardigheden beschreven met daarbij een data stewardship. In de map figuren staan alle figuren die door R studio zijn gemaakt voor de resultaten en het bevat ook de flowchart. De map bronnen bevat alle bronnen en een AI disclaimer.

## Reproduceerbaarheid

Door het beschikbaar stellen van de gebruikte R-code, de beschrijving van de workflow de originele datasets van zowel de controle groep als de RA groep en de verkregen resultaten kan de volledige transcriptomicsanalyse worden nagegaan en gereproduceerd.

Daarnaast maakt GitHub het mogelijk om wijzigingen in bestanden bij te houden en oudere versies terug te halen wanneer dat nodig is.
